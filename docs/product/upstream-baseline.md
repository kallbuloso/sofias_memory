# Upstream Baseline

Cognee is a functional reference for Sofias Memory, not the architecture to copy
wholesale.

The upstream baseline is frozen at:

```text
repository: topoteretes/cognee
branch: main
version: 1.4.1
commit: 38eece5bbb0cb9f5706fed908abd16dba0f5505e
```

Policy:

- do not follow upstream changes silently;
- every copied or adapted piece of code must keep identifiable origin information;
- preserve applicable license and notice text for derived files;
- document significant modifications;
- do not copy unnecessary modules;
- do not reuse Cognee marks, logos, or product identity for Sofias Memory;
- prefer the project architecture defined in this repository over upstream structure.
