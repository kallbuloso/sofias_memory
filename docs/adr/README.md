# Architecture Decision Records

An Architecture Decision Record (ADR) captures an important architectural decision,
the context that led to it, and the consequences of choosing it.

Create an ADR when a change sets or revises a durable technical direction, especially
when it affects persistence, security, deployment, public contracts, or project
boundaries.

Supported statuses:

- `proposed`: the decision is being discussed.
- `accepted`: the decision is active and should be followed.
- `superseded`: a newer ADR replaces this decision.

Use this file name pattern:

```text
NNNN-short-title.md
```
